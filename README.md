# Supermarket Data Pipeline

## Project Overview

This project demonstrates a data cleaning and transformation
pipeline using Python and Pandas.

## Dataset

The project uses supermarket sales data containing information
about customers, products, sales, payment methods, and ratings.

## Pipeline

Raw CSV
→ Python
→ Data Inspection
→ Missing Value Check
→ Duplicate Check
→ Data Cleaning
→ Data Type Conversion
→ Data Transformation
→ Data Validation
→ Cleaned CSV

## Technologies

- Python
- Pandas
- CSV
- VS Code
- Git
- GitHub

## Data Cleaning Steps

1. Loaded raw CSV data
2. Inspected rows and columns
3. Checked missing values
4. Checked duplicate records
5. Standardized column names
6. Cleaned text columns
7. Converted data types
8. Validated numeric values
9. Created calculated columns
10. Exported the cleaned dataset
